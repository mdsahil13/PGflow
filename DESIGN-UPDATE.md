# PGFlow design update

The CSS has been aligned with the supplied PGFlow Design System & UI Styling Specification.

Changes include:
- Plus Jakarta Sans as the primary font.
- The supplied OKLCH neutral, indigo, semantic status and sidebar tokens.
- A 224px desktop sidebar, 80px sticky header and updated content spacing.
- Spec-aligned buttons, cards, tables, status badges, occupancy indicators, room/bed chips and responsive breakpoints.
- Existing component selectors and application behavior retained to avoid breaking current React pages.

The supplied full design specification is included as `DESIGN-SYSTEM-SPEC.md`.
